## Introduction
- **Figma** is primarily used for **rapid prototyping**.  
- Goal: Create **functional prototypes without coding** to help clients visualize the product.  
- Flow: **Finalize UI (visual design) + UX (experience)** → then hand over to developers.

---

## Figma Tools Overview
- **Figma Draw** → extended tool for custom drawings.  
- **FigJam** → whiteboarding & brainstorming.  
- **Figma Sites** → alternative to Webflow / WordPress.  
- **Figma Slides** → alternative to PowerPoint.  
- **Figma Make (AI)** → website builder powered by AI.

## UI vs UX
- **UI (User Interface)** = How it looks (buttons, colors, fonts).  
- **UX (User Experience)** = How it works (flow, pain points, interactions).  
- Good UX builds trust and increases conversions.  
- Example: **Pressing Enter to submit** instead of always clicking "Submit."  
- UX best practices: remove friction, iterate quickly, solve pain points.

## Wireframes vs High-Fidelity
- **Wireframes**: skeletal layouts (basic lines/shapes).  
- **High-Fidelity**: polished, real-looking designs.  
- Workflow: Wireframe → Test → High-Fidelity.  
- Use templates later; start **manual** for learning.  
- **Frames** = like "pages"/containers for design.  
- Design **mobile-first** → then tablet → then desktop.

## Typography & Fonts
- **Two text modes**:  
  1. Click once → single-line text (good for headings).  
  2. Drag text box → multi-line paragraph text.  
- **Default font**: Inter. Alternatives: Roboto, thin-weight variations.  
- **Wireframing tip**: Stick to grayscale & blue; avoid heavy colors early.  
- **Groups vs Frames**:  
  - Delete group → group disappears.  
  - Delete frame contents → empty frame still exists.  
- **Font pairing**:  
  - [Google Fonts](https://fonts.google.com)  
  - [FontPair](https://fontpair.co)  
  - [Adobe Fonts](https://fonts.adobe.com)  
- **Common sizes**: `72px, 48px, 32px, 24px, 18px, 16px`.

## Icons & Assets
- Best source: [iconfinder.com](https://iconfinder.com), Figma community, Heroicons.  
- **SVG vs PNG**:  
  - SVG = scalable, smaller, editable → best for icons.  
  - PNG = raster, heavy, pixelates when zoomed.  
- **Quick reference**:  
  - Photo → Raster (PNG/JPG)  
  - Icon → Vector (SVG)  
  - Animation → Lottie/WebP  
- Plugins: Unsplash, Heroicons, Iconify, etc.

## Grids & Layouts
- **Desktop** → 12 columns.  
- **Mobile** → 6 columns.  
- **Mobile apps** → 8-point grid system.  
- **Gutter spacing** → multiples of 8.  
- Shortcut: `Shift + G` to toggle grid.

## Text & Character Styles
- Reusable text styles for headings, paragraphs, captions.  
- Dummy text: [Lipsum](https://lipsum.com), Content Reel plugin.  
- Line height = 150% of font size.  
- Paragraph spacing = 50% of font size.

## Working with Images
- Maintain aspect ratio by dragging **diagonal corners**.  
- Drop images directly into shapes.  
- Adjust **exposure, contrast, saturation** for better text visibility.  

---

## Masking & Cropping
- Place shape + image → use as mask.  
- Can also **fill text with images** (bold fonts work best).  

---

## Auto Layout
- Works with **frames**, not rectangles.  
- Hug contents → parent adjusts to children.  
- Typical button padding: **24px horizontal, 8px vertical**.  
- Use frames first → then apply auto layout.  

---

## Constraints & Responsiveness
- Pin elements relative to frame (top/left/bottom/right).  
- Use for responsive design.  
- Nested frames = powerful for layouts.  

---

- Like in Buttons, We can have hover state, focus state, active state and disabled state.
- So basically you are combining two components as variants.
