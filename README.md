# 🧠 Learning2025

**Learning2025** is a curated repository of code samples, micro-projects, and notes covering **Frontend, Backend, UI/UX, and DevOps fundamentals**.  
It’s designed as a personal developer’s journey — to **learn by building**, explore modern tech, and document growth throughout **2025 and beyond**.

## 🧩 About

The goal of **Learning2025** is to act as a **living digital notebook** — combining:
- 🖥️ **Frontend Development** → React, Zustand, modern JS
- ⚙️ **Backend Systems** → Node.js, RabbitMQ, APIs
- 🎨 **UI/UX Design** → Figma, Google UX coursework
- 💡 **Automation & Scripts** → Handy `.mjs` utilities
- 📘 **Software Practices** → Architecture, Git, patterns

Every directory in this repo is a focused micro-learning unit with practical examples.
